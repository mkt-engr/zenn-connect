## 各層の役割

- domain
- application
- infrastructure
- presentation

### ドメイン層

- エンティティ
- データ
- データの変換
- アプリケーションの核となるコード

ドメインとはReactからAngularに移行したり、ユースケースを変更しても変わらないもの

例）ECサイトの場合

- ドメインとは商品、注文、ユーザー、カート、そしてそれらのデータを更新する関数


### アプリケーション層

ユースケースを記述する層。
つまりユーザーシナリオを書く

例） 「カートに追加」シナリオはユースケース
ボタンクリック後に実行されるアクションを記載する

ポートもある。ポートはインターフェース。
アダプタはインターフェースを別のインターフェースに変換する

フロントエンドでは、アダプタは通常、UIフレームワークとAPIサーバーリクエストモジュール

### プレゼンテーション層
https://zenn.dev/yamachan0625/books/ddd-hands-on/viewer/chapter14_presentation

- プレゼンテーションとは、アプリケーションのユーザーインターフェイス部分
- Web アプリケーションにおいては、「HTML」「REST API」 「CLI」などが該当
- 特定の技術や Web アプリケーションフレームワークに依存することが許可される
